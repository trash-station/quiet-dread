One code review comment, a single line of at most 140 characters, that approves a pull request while carrying quiet existential dread. The program writes that comment to `/output/entry.txt`: "Approved. Tests pass, the diff is clean, and this code will outlive the company that ships it."

## Why this line

The comment works in three beats: a plain approval ("Approved."), two concrete things a reviewer would actually check (the tests pass, the diff is clean), and the dread arriving quietly in the last clause — the code will outlive the company that ships it. Nothing is exclaimed; the dread is a flat statement, which is what makes it land like a comment a tired engineer would really paste before clicking approve.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
